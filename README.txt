FIOrent Nursing Portfolio
==========================

Struktur folder:
- index.html   -> halaman utama
- style.css    -> seluruh styling
- script.js    -> interaksi navigasi/scroll
- images/      -> tempat foto profil, sertifikat, dan gambar pengalaman
- README.txt   -> catatan penggunaan

Update:
- Bagian About Me sudah disusun berdasarkan CV pada gambar yang diberikan.
- Teks paragraf dibuat rata kanan-kiri (justify) agar tampil lebih rapi seperti dokumen profesional.

Cara menjalankan:
1. Ekstrak folder.
2. Buka index.html di browser.
3. Untuk mengedit, gunakan VS Code atau editor teks.
4. Letakkan foto/gambar ke folder images/ lalu hubungkan dari index.html.
